# Этап 4: Instagram, режим оператора, уведомления

Код написан, но **Instagram не подключён** (так решено). Сначала проверяем бота через
`POST /v1/messages` и песочницу админки. Тесты проходят (прогон 2026-10-02).

## Что сделано

- **Вебхук Instagram** `POST /v1/channels/instagram/webhook`:
  - проверяет подпись `X-Hub-Signature-256`;
  - сохраняет сообщение и сразу отвечает Meta 200;
  - ход бота запускает задача `run_turn` после паузы склейки (в настройках канала —
    `merge_pause_s`, по умолчанию 5 с; не дольше `merge_max_wait_s` от первого сообщения).
  - Канал определяется по `recipient.id` (наш аккаунт), клиент — по `sender.id`.
- **Echo** — копия исходящего сообщения от Meta:
  - если это наш ответ, ничего не делаем;
  - если человек ответил прямо из приложения Instagram, сообщение сохраняется как ответ
    оператора, а открытые варианты закрываются.
- **Окно 24 часа.** Бот пишет клиенту только в течение 24 часов после последнего сообщения
  клиента. Оператор может писать до 7 дней, если включён `IG_HUMAN_AGENT_TAG` (нужно
  разрешение Meta Human Agent).
- **Подключение аккаунта из админки.** Раздел «Каналы»:
  - кнопка «Подключить Instagram» ведёт на вход через Instagram;
  - запасной путь для тестов — «Добавить токен» (вставить токен руками).
  - Токен живёт 60 дней. Задача `refresh_ig_token` продлевает его заранее.
- **Режим оператора** (галочка у канала или у диалога):
  - бот не отвечает сам, а готовит 3–4 варианта ответа;
  - оператор выбирает вариант, правит его или пишет свой;
  - новое сообщение клиента пересобирает варианты, у задачи растёт версия. Выбор по
    старой версии отклоняется с ошибкой «варианты устарели».
- **Передача человеку.** Клиент просит человека, или срабатывает действие `handover` →
  бот замолкает в этом диалоге, создаётся задача в очереди оператора и уходит
  уведомление. Кнопка «Вернуть боту» снимает передачу.
- **Уведомления** (раздел «Уведомления»): Telegram-бот или почта.
  - Подписка на события: передача человеку, варианты ждут выбора, ошибка канала.
  - В сценарии: действия `notify_telegram` и `notify_email` с параметром `notifier`.
  - Кнопка «Проверить» шлёт тестовое сообщение сразу.
- **Новые действия сценария:**
  - `message_client` — написать клиенту текст `{язык: текст}`;
  - `handover` — передать диалог человеку.

## Как подключить Instagram потом

1. Выпустить **новые** токены. Старые из репозитория ecom-chat засвечены в git.
2. Создать приложение Meta («Instagram API with Instagram Login») и заполнить `.env`:
   - `META_APP_ID`, `META_APP_SECRET`;
   - `IG_WEBHOOK_VERIFY_TOKEN` — любая случайная строка.
3. В настройках приложения Meta указать:
   - Webhook URL: `$PUBLIC_API_URL/v1/channels/instagram/webhook`, поле `messages`;
   - Verify token — то же значение, что в `.env`;
   - OAuth redirect URI: `$ADMIN_URL/api/v1/admin/channels/instagram/callback`.

   Все адреса показаны в админке внизу страницы «Каналы», их можно скопировать.
4. Добавить свой Instagram-аккаунт тестером приложения. Пока Meta не одобрила
   приложение (App Review), подключаются только тестеры.
5. В админке нажать «Подключить Instagram».
6. Проверить: вебхук → ответ бота → режим оператора → выбор варианта → клиент получил
   ответ.
